| P0 | Evidence classification (R12) | New deterministic `assess_evidence` agent tool and `/api/evidence-assessment` route. The scenario has these dimensions: phenomenon, fuel class or material, gravity, O₂, pressure and flow. Each investigation gets a per-dimension `match` / `differs` / `unknown` status from curated facets plus measured ranges from the bundle. Classification: **Direct** = flight data in the requested gravity regime with the material, phenomenon and every requested numeric condition matched by measured runs. **Indirect** = the phenomenon or fuel class matches but a key condition differs, is unknown or is simulated. **Insufficient** = nothing qualifies. Simulated partial-g is never Direct; microgravity is never treated as lunar or Martian. Output is an `evidence_assessment` artifact with explicit evidence gaps and the tests needed. | `science/assessment.py` (new), `tools.py`, `agent/registry.py`, `main.py`, artifact schema | Unit tests: lunar acrylic → Indirect, never Direct; microgravity cotton fabric with flow → Direct (Saffire); unsupported condition → Insufficient |
