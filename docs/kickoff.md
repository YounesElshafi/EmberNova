# Team kickoff

| Decision | Notes |
| --- | --- |
| Challenge brief | Official URL and the requirement we are addressing |
| Audience | Who has the problem, and when? |
| Demo goal | What should someone be able to do by the end of the demo? |
| Scope | One flow to build now; list what can wait |
| Data | Source URL, license or attribution, and known limitations |
| Owners | Data, prototype, testing, demo, and submission |
| First checkpoint | Time and what the team should be able to show |

First checkpoint: load a representative data sample and walk through the demo flow. If the data source fails, agree on a fallback before building around it.
