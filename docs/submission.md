# Submission checklist

- [ ] Confirm the requirements for the selected challenge and local event.
- [ ] Add the project summary, screenshots, and setup instructions to the README.
- [ ] Document data sources, attribution, and the prototype's limitations.
- [ ] Test the demo from a fresh setup and record a backup walkthrough.
- [ ] Check that judges can access every link included in the submission.
- [ ] Submit through the Project tab on the team page and verify the submission.

The [official 2026 event page](https://www.spaceappschallenge.org/2026/) lists the submission deadline as November 15 at 11:59 PM local time.
