Method

Evidence, not verdicts

01 — TRACEABLE

Every claim has a source

Each insight links back to the experiment it came from. We separate raw measurements, published results and AI-written summaries, so nothing is presented as more certain than it is.

02 — TRANSPARENT

Ranking you can inspect

Relevance is a weighted similarity between your scenario and each experiment. Open "Why this rank" on any card to see the breakdown. Relevance is not the same as strength of evidence, so we show both separately.

03 — HONEST

We show what's missing

If no experiment matches your conditions, the gap detector says so, lists the closest evidence and suggests which test would close the gap. For example, there is no partial-gravity combustion data yet for lunar conditions.

Important. emberNova helps researchers explore and compare existing evidence. It is not a safety certification and does not replace engineering safety testing. The flame animation is a simplified educational illustration, not a scientific simulation. Missing values are shown as Not Available; guide fills are labeled separately from PSI values.
